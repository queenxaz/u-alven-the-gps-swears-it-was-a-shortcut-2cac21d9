A GPS defends its shortcut: four minutes saved, two tyres, one marriage and a ferry lost. The map said 'adventure'.

## The entry

> That 'shortcut' was a goat track, a dead end and one very angry farmer. But the sunset was free, Judge — and I saved you three whole minutes.

(141 characters, limit 200.)

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
